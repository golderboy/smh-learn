# การจัดการหลักสูตรและบทเรียนบน PC DEV

> ระบบสอบ รายงานและแต้มล่าสุด รวมการเปิดแต้มตามรอบเรียน ดู [คู่มือ Phase 4–6](manuals/admin-guide.html)

ปรับปรุง 8 ตุลาคม 2569 ตามคำตอบเจ้าของระบบ: YouTube/MP4 โดยตรง เรียนเรียงบท และทบทวนบทเดิมได้ ใช้ร่วมกับ [คู่มือ Phase 4](manuals/user-guide.html) และใช้แทนรายละเอียดการจัดบท/สื่อในคู่มือรอบก่อน

## จัดจำนวนบทและเนื้อหา

เปิด [จัดการหลักสูตร](http://127.0.0.1:8088/manage/courses) ด้วย Admin หรือ Instructor ที่ Admin มอบหมายหมวดหลักสูตรให้

1. เลือกหลักสูตรและเวอร์ชันฉบับร่าง เพิ่มหมวดและบทได้ตามจำนวนที่ต้องการ ระบบแสดงจำนวนบทที่ผู้เรียนเห็น
2. กำหนดชื่อ ลำดับ สถานะและเนื้อหาที่จำเป็น ลดจำนวนบทโดยนำออกจากฉบับร่าง หรือปิดใช้บทนั้น
3. ในบทเลือก **แนบเนื้อหาและเอกสาร** เพิ่มวิดีโอ MP4 ที่อัปโหลด, ลิงก์ YouTube หรือ URL HTTPS ของไฟล์ `.mp4` โดยตรง แนบวิดีโออย่างเดียวได้ ไม่บังคับมีเอกสาร
4. แนบ PDF, ภาพ JPG/PNG/WebP หรือ HTTPS link ได้หลายรายการในบท เลือกว่าแต่ละเอกสารจำเป็นต้องยืนยันอ่านหรือเป็นเนื้อหาเพิ่มเติม
5. กำหนดลำดับหมวดและบทก่อนเผยแพร่ หากลำดับซ้ำ ระบบเรียง ID ให้ลำดับคงที่
6. เผยแพร่แล้วตรึงบท เนื้อหาและการจับคู่ PDF หากต้องแก้ให้สร้างเวอร์ชันใหม่ รอบเดิมและประวัติเดิมยังใช้เวอร์ชันเดิม

การนำบทหรือเนื้อหาออกจากฉบับร่างไม่ลบไฟล์สื่อร่วมของเวอร์ชันเก่า เก็บไฟล์จริงและ Audit ไว้

## วิดีโอและเอกสาร

- อัปโหลด MP4/PDF/ภาพไม่เกิน 100 MiB ต่อไฟล์ ตรวจ extension และ MIME จริง ภาพต้องอ่านขนาดได้ ไม่เกิน 40 ล้านพิกเซล ไม่รองรับ SVG
- MP4 ที่อัปโหลดอ่านระยะเวลาฝั่ง Server; ลิงก์ภายนอกให้ Instructor ระบุระยะเวลาจริงเป็นวินาทีปัดขึ้น เช่น 5.055 วินาทีระบุ 6 ตัวเล่นและ Heartbeat ตรวจว่าตรงก่อนนับเวลา
- ก่อนเล่นหรือกลับมาเล่นต่อ ตัวเล่นรอ Server ตอบรับการเริ่มบันทึกก่อนปล่อยคลิป เพื่อไม่ให้เวลาเปิดคำขอทำให้เกณฑ์ 100% ขาดช่วงต้น หากตอบรับไม่สำเร็จวิดีโอหยุดและแจ้งข้อผิดพลาด
- YouTube รองรับ watch, youtu.be, embed และ shorts ของหนึ่งคลิป ใช้ [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference) และ [พารามิเตอร์ตัวเล่น](https://developers.google.com/youtube/player_parameters) คลิปต้องอนุญาตการฝังและเครือข่ายเปิดเล่นได้ ไม่ใช้ playlist/live stream เป็นบทเรียนที่วัดด้วยความยาวคงที่
- URL MP4 ต้องเป็น HTTPS และ path ลงท้าย `.mp4` (มี query ได้) Browser อ่านโดยตรง ไม่ดาวน์โหลด URL ภายนอกผ่าน Server
- ไม่มีตัวเลื่อนตำแหน่งวิดีโอ ใช้ปุ่มเล่น/หยุด เสียงและเต็มจอด้วยความเร็วปกติ Server ปฏิเสธตำแหน่งกระโดดเกินเวลาที่ผ่านไป
- เมื่อผ่านเกณฑ์แล้วกลับมาทบทวนและ **ดูซ้ำตั้งแต่ต้น** ได้ ช่วงซ้ำไม่เพิ่มเวลาสะสมซ้ำซ้อน
- เกณฑ์ 100% ใช้ความยาวจริงที่ตรงกับค่าระบุ และยอมรับความคลาดเคลื่อนนาฬิกาเมื่อเล่นถึงจบได้ไม่เกิน 2% หรือ 1.25 วินาที (ค่าที่น้อยกว่า) เวลาสะสมยังถูกจำกัดด้วยเวลาฝั่ง Server ไม่อนุญาตกระโดดไปท้ายคลิป
- PDF/ภาพแสดงใต้คลิปอัตโนมัติ ลิงก์เอกสารมีปุ่มเปิดใต้คลิป เอกสารที่จำเป็นต้องเปิดและยืนยันอ่านเพื่อจบบท

## เรียนตามลำดับ

1. สมัครหรือรับมอบหมาย แล้วส่ง Pretest ให้ครบ ไม่บังคับคะแนนขั้นต่ำ
2. เริ่มบทแรก เมนูบทข้างหน้าถูกปิด Server ปฏิเสธการเปิด URL/สื่อและส่งความก้าวหน้าข้ามบทด้วย
3. **บทถัดไป** ถูกปิดจนวิดีโอและเอกสารที่จำเป็นของบทปัจจุบันถึงเกณฑ์ หากบทไม่มีเนื้อหาที่ระบุจำเป็น ใช้เนื้อหาทั้งหมดของบทเป็นเกณฑ์การไปต่อ
4. บทที่ผ่านมาเปิดทบทวนได้ การยืนยันอ่านอัปเดตหน้าจอแม้เปอร์เซ็นต์รวมหลักสูตรยังเท่าเดิม
5. เรียนครบเกณฑ์หลักสูตรแล้วต้องส่ง Posttest อย่างน้อย 1 ครั้ง จบได้แม้คะแนนไม่ผ่านเกณฑ์อ้างอิง จำนวนครั้งรวมตั้งจากระบบโดย Instructor ค่าเริ่มต้น 1 ครั้ง ใช้เปอร์เซ็นต์คะแนนสูงสุดสรุปผล

## เอกสารทั้งหลักสูตร

ที่ [หน้าหลักสูตรวิชาระเบียบวิธีวิจัย](http://127.0.0.1:8088/courses/1) มี **เอกสารประกอบการเรียนทั้งหลักสูตร** หลังทำ Pretest จะแสดง PDF/ภาพทุกบทและลิงก์ ดาวน์โหลดไฟล์ทีละรายการได้ครบ รวมเอกสารของบทที่ยังล็อก

การดาวน์โหลดไม่เปิดบทถัดไปและไม่ถือว่ายืนยันอ่าน ต้องกลับมาเรียนและยืนยันในบทที่เปิดตามลำดับ ยังคงตรวจเจ้าของ Enrollment, เวอร์ชัน, รอบเปิดและการยกเลิก

วิชาทดสอบเดิมเก็บ 24 รายการโครงบทในฐานข้อมูล (14 วิดีโอและ 10 แหล่ง PDF) เอกสารที่จับคู่ใต้คลิปเป็นเอกสารประกอบ จึงแสดงให้ผู้เรียน **16 บท**: 14 บทวิดีโอและ 2 บทอ่านแยก (เอกสารทั่วไป/บท 11) ไม่ลบหรือสร้างประวัติใหม่จากการจัดหน้าจอ

PHP ผ่าน **78 กรณี / 848 assertions**, Component **12 กรณี**, Pint/PHPStan/Typecheck/Lint/Format/Build ผ่าน MariaDB/Redis/Storage/Queue/Scheduler ตรวจผ่านบน DEV

Browser รวม **9 กรณีผ่านจากการตรวจหลายรอบ**: Environment/Foundation 6 กรณี และ workflow บทเรียน/ข้อสอบ 3 กรณีครบ Desktop 1440×900, Tablet 768×1024, Mobile 390×844 หลังแก้การรอ Server ก่อนเล่น Desktop/Tablet ผ่านในรอบเดียว ส่วน Mobile ทดสอบซ้ำผ่านหลังเพิ่มเวลารอ metadata ของ MP4 ภายนอกจาก 15 เป็น 30 วินาที (Trace รอบที่หยุดมีคำขอภายนอกค้าง ยังไม่มี HTTP response)

ตรวจภาพสองรอบครบทุกขนาด: เอกสารทั้งหมด, ยืนยันอ่านแล้วปลดล็อก Next, MP4 ถึงเกณฑ์ 100%, YouTube เล่นจริง, ภาพประกอบ และผลสอบ ตรวจ title/URL/Page/HTTP/assets/framework overlay และไม่พบหน้าเว็บล้นแนวนอนในเส้นทางที่ผ่านทดสอบ เก็บภาพใน `course-lesson-pass1` และ `course-lesson-pass2` ภายใต้โฟลเดอร์ visualizations ของแชตนี้ ใช้ Playwright E2E เดิมในโครงการ เพราะ Browser plugin ไม่พร้อมใน session นี้

มีคำเตือนเฉพาะจาก YouTube/Chromium เช่น `web-share`, GPU adapter และ `powerPreference` บน Windows เก็บแยกเป็น `youtube-provider-diagnostics` ในผลทดสอบ ไม่ใช่ Console ที่สะอาดทั้งหมด ส่วน Page error, Console error/คำเตือนอื่น และ HTTP ตั้งแต่ 400 ยังทำให้การทดสอบล้มเหลว

ตรวจข้อมูลหลังจบ: ไม่เหลือหลักสูตร QA, บัญชีจำลอง 10 คนคืนรหัสผ่านตั้งต้นและบังคับเปลี่ยนรหัสผ่านครบ, ผู้คุมหมวดหลักยังเป็นผู้ใช้จำลอง 04 คนเดียว หลักสูตรจริงยังมี Pretest 20/Posttest 30 ข้อแบบปรนัยคำตอบเดียว เปิดรอบเรียนและบังคับสอบทั้งสองประเภท ไม่มีผลจบหลักสูตรหรือ Posttest หลักที่สร้างขึ้นเพื่อทดสอบหน้าจอ

รัน HTTP/PHP/Browser tests หลัง Build เสร็จ เพราะระหว่าง Build อาจลบ manifest/chunks ชั่วคราว PHPUnit ใช้ `smh_learning_test` แยก Browser ใช้ fixture QA ใน DEV และล้างเฉพาะ fixture/คืนรหัสผ่านจำลองหลังทดสอบ
