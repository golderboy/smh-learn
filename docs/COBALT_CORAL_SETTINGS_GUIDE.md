# การตั้งค่าชื่อและภาพเว็บไซต์ — Cobalt Coral

ใช้กับระบบบน PC DEV ที่ http://127.0.0.1:8088/admin/settings

ผู้ดูแลที่มีสิทธิ์ `settings.manage` เปิดเมนู **บริหารระบบ → ตั้งค่าระบบ** เพื่อปรับเว็บไซต์ให้เหมาะกับองค์กรที่ติดตั้งระบบของตนเอง ข้อมูลการเรียน หลักสูตร และผลสอบใช้กติกาเดิม

## สิ่งที่ปรับได้

| ส่วน | การตั้งค่า |
| --- | --- |
| ชื่อเว็บไซต์ | ชื่อระบบ และชื่อองค์กร ใช้ในเมนู ส่วนหัว และชื่อแท็บ รวมหน้า Error เมื่ออ่าน Settings ได้ |
| Dashboard | ข้อความหัวหน้า คำอธิบายส่วนหัว และข้อความประกอบแบนเนอร์ |
| หน้าเข้าสู่ระบบ | หัวข้อและคำอธิบาย |
| ภาพ | โลโก้/ไอคอนเว็บไซต์ ภาพแบนเนอร์ และไอคอนแท็บเบราว์เซอร์ |
| ท้ายเว็บไซต์ | ข้อความท้ายเว็บไซต์ อีเมล โทรศัพท์/เบอร์ภายใน และลิงก์ติดต่อหรือคู่มือ |
| ภาพเมนู | เปิด/ปิดภาพประกอบส่วนท้าย Sidebar บนจอขนาดใหญ่ที่มีพื้นที่ |
| การเข้าใช้งาน | ระยะเวลาไม่ใช้งานก่อนหมดอายุ 15–240 นาที ตามนโยบายที่ระบบรองรับอยู่เดิม |

ข้อความเป็นข้อความธรรมดา ไม่ต้องใส่ HTML ลิงก์ติดต่อใช้ `http://` หรือ `https://` ช่องทางติดต่อที่เว้นว่างจะไม่แสดง

## วิธีเปลี่ยนภาพและข้อความ

1. กรอกข้อความที่ต้องการ และเลือกไฟล์ภาพขององค์กร ตัวอย่างด้านขวาหรือด้านบนบนมือถือจะเปลี่ยนทันที แต่ยังไม่มีผลกับผู้ใช้คนอื่น
2. ใช้ภาพ PNG, JPG/JPEG หรือ WebP ที่เปิดอ่านได้ โลโก้และไอคอนแท็บไม่เกิน 2 MB แบนเนอร์ไม่เกิน 5 MB และแต่ละภาพไม่เกิน 16 ล้านพิกเซล
3. โลโก้พื้นโปร่งใสอ่านง่ายบนเมนูกรมท่า ไอคอนแท็บควรเป็นสี่เหลี่ยมจัตุรัส แบนเนอร์ใช้ภาพแนวนอนหรือภาพพื้นโปร่งใส โดยข้อความชื่อหลักสูตรยังแสดงจากข้อมูลจริงบนเว็บ
4. กด **บันทึกการตั้งค่า** แล้วตรวจ Dashboard กับหน้าเข้าสู่ระบบ การตั้งค่ามีผลกับการเปิดหน้าถัดไปหรือการโหลดหน้าใหม่
5. หากต้องการยกเลิกภาพที่อัปโหลด ให้เลือก **กลับไปใช้ภาพมาตรฐาน** ของภาพนั้นแล้วบันทึก ชื่อและข้อความที่กำหนดยังคงอยู่

หากกรอกข้อมูลผิดหรือไฟล์ไม่รองรับ ระบบแจ้งใกล้ช่องและสรุปข้อผิดพลาด ค่าที่กำลังกรอกยังคงอยู่ หากออกจากหน้าก่อนบันทึกจะมีข้อความยืนยันก่อนทิ้งข้อมูล

## สำหรับผู้ดูแลเครื่อง

ค่าที่กำหนดเก็บใน `system_settings` เดิม ส่วนไฟล์ที่อัปโหลดเก็บใต้ `storage/app/private/branding` และเปิดผ่าน URL ของชนิดภาพกับ hash ปัจจุบัน ไม่ต้องสร้าง public storage link สำหรับภาพเหล่านี้

การสำรอง/ย้ายเครื่องต้องเก็บฐานข้อมูลพร้อม `storage/app/private` การตรวจ source ของเครื่องมือ Phase 10 พบว่ารวม private storage ทั้งโฟลเดอร์อยู่แล้ว รูปมาตรฐานและฟอนต์เป็นส่วนหนึ่งของ source/build ของเว็บไซต์

ระบบไม่เปิดให้ใส่ CSS/JavaScript หรือค่าลับจากหน้านี้ การตั้งค่ารอบสอบ เกณฑ์การเรียน และสิทธิ์ผู้คุมยังอยู่ในหน้าจัดการตามขอบเขตเดิม ภาพเดิมที่แทนที่/กลับค่าเริ่มต้นไม่อยู่ใน URL ปัจจุบัน และยังเก็บไฟล์ไว้ใน private storage เพื่อรักษาสำเนาเดิม ไม่มีเมนูล้างไฟล์ย้อนหลังในรอบนี้
