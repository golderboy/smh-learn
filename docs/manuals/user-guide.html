เตรียม→ทำทีละขั้น→ตรวจผล→ใช้งาน

ภาพอธิบายขั้นตอน ไม่ใช่ภาพหน้าจอของระบบปฏิบัติการ

ไม่ต้องติดตั้งโปรแกรมเพิ่ม ใช้Chrome/Edgeและบัญชีที่หน่วยงานจัดให้ ภาพทุกภาพเป็นข้อมูลสมมติจากการทดสอบจริง

สำหรับผู้เริ่มต้น · ภาพประกอบและข้อมูลสมมติจากชุดทดสอบ

เปิดอ่านตามหัวข้อ

  1. เข้าเว็บไซต์และเปลี่ยนรหัสครั้งแรก
  2. รู้จักเมนูและเลือกหลักสูตร
  3. ทำ Pretest ก่อนเริ่มเรียน
  4. ดูวิดีโอและเอกสารให้ครบตามเกณฑ์
  5. เรียนเรียงบทและดาวน์โหลดเอกสาร
  6. ทำ Posttest และดูคะแนนสรุป
  7. ตรวจแต้มและรายงานของตนเอง
  8. แลกแต้มเป็นบัตรคูปองออนไลน์
  9. หลังใช้คูปอง ออกจากระบบ และขอความช่วยเหลือ
อ่านจาก HTML: คลิกภาพเพื่อเปิดภาพเต็มและขยายดูข้อความได้ คัดลอกคำสั่งจาก HTML เพื่อคงบรรทัดเดิม อ่านจาก PDF: ใช้ปุ่มขยาย 150–200% และค้นหาคำด้วย Ctrl+F ไฟล์ HTML อยู่ใน source ZIP ที่ docs/manuals/index.html ภาพที่แสดงชื่อบุคคลใช้ข้อมูลสมมติทั้งหมด

ขั้นตอน / หัวข้อ 1

เข้าเว็บไซต์และเปลี่ยนรหัสครั้งแรก

  1. เปิดChrome/Edge ใช้ที่อยู่เว็บไซต์ที่หน่วยงานแจ้ง พิมพ์ในช่องที่อยู่ด้านบนแล้วกดEnter
  2. ใส่เลขบัตรประชาชน/เลขประจำตัวที่Adminนำเข้า กรอกเลขครบรวม0นำหน้า รหัสครั้งแรก learn123456 ถ้าเคยเปลี่ยนแล้วใช้รหัสล่าสุด
  3. กดเข้าสู่ระบบ ตั้งรหัสใหม่อย่างน้อย10ตัวอักษรและยืนยันให้ตรงกัน ก่อนเข้าDashboard
  4. ถ้าลืมรหัสติดต่อAdmin อย่าส่งรหัสให้เพื่อน ช่องThaiDอาจยังปิดตามการตั้งค่าองค์กร
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 2

รู้จักเมนูและเลือกหลักสูตร

  1. หน้า ภาพรวม แสดงงานเรียนและความก้าวหน้า เมนูด้านซ้ายเลือกการเรียนของฉัน/หลักสูตรทั้งหมด/แต้ม/คูปอง
  2. ถ้าจอแคบให้กดปุ่มเมนู ใช้การเรียนของฉันเพื่อกลับไปวิชาที่สมัครแล้ว
  3. เปิดหลักสูตรทั้งหมด เลือกชื่อวิชา อ่านรายละเอียดและรอบที่เปิด
  4. ถ้าเปิดสมัครเองให้กดสมัครเรียน หากไม่มีปุ่มให้สอบถามAdminเรื่องการมอบหมายหรือวันเปิดรอบ
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 3

ทำ Pretest ก่อนเริ่มเรียน

  1. เข้าหลักสูตรแล้วกดทำPretestก่อนเรียน เลือกคำตอบเดียวต่อข้อ มี4–6ตัวเลือกตามข้อสอบ
  2. ระบบบันทึกคำตอบอัตโนมัติ ตรวจว่าบันทึกแล้วก่อนออกจากหน้า สามารถกลับมาทำต่อในครั้งเดิมตามเวลาที่ตั้ง
  3. ตอบให้ครบ กดส่งข้อสอบและดูผล แล้วกดยืนยันส่ง เมื่อส่งแล้วแก้คำตอบครั้งนั้นไม่ได้
  4. แม้ได้0%ก็เริ่มเรียนได้ Pretestใช้ประเมินก่อนเรียน ไม่ใช่คะแนนผ่านเพื่อปลดล็อก
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 4

ดูวิดีโอและเอกสารให้ครบตามเกณฑ์

  1. เลือกบทแรก วิดีโอและเอกสารของบทแสดงในหน้าเดียวกัน เอกสารประกอบอยู่ใต้คลิป เลื่อนหน้าลงเพื่ออ่าน
  2. กดเล่นวิดีโอ รับชมความเร็วปกติ เลื่อนข้ามคลิปไม่ได้ ดูเปอร์เซ็นต์รับชมที่ระบบแสดง อย่าเปิดหลายแท็บเพื่อเร่งเวลา
  3. อ่าน PDF/ภาพ/บทความที่กำหนด จากนั้นกดยืนยันว่าอ่านแล้ว เอกสารที่จำเป็นต้องยืนยันเพื่อจบบท
  4. เมื่อกลับเข้าบทเรียน ระบบใช้ความก้าวหน้าเดิม และเปิดให้ทบทวนบทที่ผ่านแล้วได้
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 5

เรียนเรียงบทและดาวน์โหลดเอกสาร

  1. กดบทถัดไปเมื่อปุ่มเปิด หรือเลือกบทที่ปลดล็อกในเมนู หากปุ่มปิดให้ตรวจเปอร์เซ็นต์วิดีโอและเนื้อหาจำเป็น
  2. เรียนเรียงบท เปิดบทข้างหน้าไม่ได้จนบทปัจจุบันครบเกณฑ์ กลับบทเดิมเพื่อทบทวนได้
  3. ใช้เอกสารทั้งหลักสูตรกลับหน้าหลักสูตร หลังส่งPretestแล้วดาวน์โหลดเอกสารประกอบทั้งหมดได้
  4. การดาวน์โหลดไม่เท่ากับยืนยันอ่าน ต้องกลับมากดอ่านแล้วในบทที่กำหนด เมื่อบททั้งหมดครบจะขึ้นรอPosttest

ถ้าไม่มีคลิป บทอ่านก็ต้องเปิดอ่านและยืนยันตามที่Instructorกำหนด ไม่จำเป็นต้องมีวิดีโอทุกบท

ขั้นตอน / หัวข้อ 6

ทำ Posttest และดูคะแนนสรุป

  1. เมื่อเรียนครบกดทำPosttestหลังเรียน เลือกคำตอบเดียวจากก–ฉตามจำนวนตัวเลือกของข้อนั้น
  2. ตรวจทุกข้อ กดส่งและยืนยัน ระบบตรวจคะแนนทันทีและเก็บคำตอบครั้งนี้
  3. จบหลักสูตรเมื่อเรียนครบและส่งPosttestอย่างน้อยหนึ่งครั้ง ไม่บังคับคะแนนผ่านสำหรับการจบ แต่โบนัสผ่านเกณฑ์อาจแยกกัน
  4. ทำซ้ำได้ไม่เกินจำนวนครั้งรวมที่Instructorตั้ง ค่าเริ่มต้น1ครั้ง ใช้คะแนนPosttestสูงสุดสรุปผล หากใช้ครบปุ่มสอบซ้ำจะปิด
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 7

ตรวจแต้มและรายงานของตนเอง

  1. เลือกแต้มของฉัน ตรวจยอดและประวัติรายการ สามารถแยกโบนัสกับรายการแลกคูปองได้
  2. กฎตัวอย่างจบ+20 ผ่านเกณฑ์+30 คะแนนสูงสุด≥90%เพิ่ม+10 ให้แต่ละโบนัสหนึ่งครั้งต่อคนต่อรอบ
  3. เปิดรายงานผลการเรียนของตนเพื่อดูคะแนนและสถานะ หากสงสัยชื่อแผนกเก่า รายงานใช้ข้อมูล ณ สมัครเรียน
  4. ถ้าคะแนน/แต้มไม่ตรงให้แจ้งAdminพร้อมชื่อวิชา รอบและวันที่ อย่าสมัครซ้ำหรือกดส่งซ้ำเพื่อเพิ่มแต้ม

ขั้นตอน / หัวข้อ 8

แลกแต้มเป็นบัตรคูปองออนไลน์

  1. เลือกคูปองของฉัน ดูชื่อร้าน มูลค่าส่วนลด แต้มที่ใช้และจำนวนคงเหลือ
  2. เลือกคูปองที่แต้มเพียงพอ กดแลก อ่านยอดแต้มหลังหักและเงื่อนไข ก่อนยืนยัน
  3. เมื่อสำเร็จได้บัตรออนไลน์ ใช้เฉพาะร้านที่ระบุและภายใน90วันนับจากเวลาที่แลก
  4. เปิดบัตรต่อหน้าร้าน กดแสดงรหัสให้ร้าน ให้ร้านตรวจและยืนยันรับในระบบก่อนรับส่วนลด อย่าเผยรหัสในโพสต์หรือส่งให้คนอื่น
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 9

หลังใช้คูปอง ออกจากระบบ และขอความช่วยเหลือ

  1. หลังร้านยืนยันรับ บัตรเปลี่ยนเป็นใช้แล้ว นำไปใช้ซ้ำไม่ได้ แม้มีภาพบัตรเดิม
  2. ถ้าคูปองถูกใช้หรือหมดอายุ ให้ตรวจวันที่และชื่อร้าน ติดต่อAdminตามข้อมูลหน่วยงาน ร้านต้องรับผ่านระบบทุกครั้ง
  3. เมื่อใช้คอมพิวเตอร์ร่วมกับคนอื่น กดบัญชีของฉัน → ออกจากระบบ อย่าบันทึกรหัสในเครื่องสาธารณะ
  4. ส่งปัญหาให้Adminเป็นชื่อหลักสูตร รอบ บท วันเวลาและภาพที่ปิดบังเลขประจำตัว/รหัสคูปอง ไม่ส่งรหัสผ่าน
ถ้าเว็บแจ้งใบรับรองไม่ปลอดภัย อย่ากดข้ามเพื่อกรอกรหัสบนระบบจริง ให้ติดต่อหน่วยงาน ถ้าปุ่มบทถัดไปยังปิด ตรวจเนื้อหาที่จำเป็นก่อน ถ้าไม่ดีขึ้นให้แจ้งAdmin
