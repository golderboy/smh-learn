ขั้นตอน / หัวข้อ 1

เข้าระบบและรู้จักสิทธิ์

  1. เปิดเว็บไซต์ที่ IT แจ้งลงท้าย /login ใช้ admins และรหัสแรก P@ssw0rd112233 เฉพาะการติดตั้งใหม่ เปลี่ยนรหัสอย่างน้อย10ตัวอักษรทันที
  2. หลังเปลี่ยนรหัสจะเห็นเมนูด้านซ้าย หากจอเล็กให้กดเมนู เลือกหัวข้อที่ต้องการ
  3. บัญชี admins เป็นบัญชีสงวน คนอื่นแก้ชื่อ บทบาท สถานะ หรือรีเซ็ตให้ไม่ได้ เจ้าของเปลี่ยนรหัสของตัวเองได้
  4. แอดมินรองสร้างได้หลายคน Instructor ต้องได้รับมอบหมายหมวด ร้านต้องได้รับมอบหมายร้านและอนุมัติ
บัญชีผู้ดูแลเป็นรายบุคคล ไม่ส่งรหัส admins ให้ทุกคน ผู้ลืมรหัสติดต่อ Admin ส่วนรหัสของบัญชีสงวนให้เจ้าของจัดการเอง

ขั้นตอน / หัวข้อ 2

ตั้งชื่อ ภาพ และข้อความหน่วยงาน

  1. เลือก บริหารระบบ → ตั้งค่าเว็บไซต์ ตรวจแต่ละกลุ่มตั้งค่า
  2. เปลี่ยนชื่อหน่วยงาน ชื่อเว็บไซต์ ข้อความ Header คำต้อนรับ และข้อมูลติดต่อให้ตรงหน่วยงาน
  3. อัปโหลดโลโก้/แบนเนอร์หรือเลือกภาพที่ระบบรองรับ ตรวจตัวอย่างก่อนบันทึก
  4. กดบันทึก แล้วเปิดหน้า login หรือ dashboard ใหม่เพื่อตรวจข้อความจริง ถ้าไม่พบการเปลี่ยนให้รีเฟรชหน้า

ตั้งค่าภาพ/ข้อความได้โดยไม่แก้โค้ด ค่าโครงสร้างหลัก เช่น APP_KEY รหัสฐานข้อมูล และ ThaiD ให้ผู้ดูแลเซิร์ฟเวอร์จัดการตามคู่มือติดตั้ง

ขั้นตอน / หัวข้อ 3

นำเข้าข้อมูลพื้นฐานจาก Excel

ดาวน์โหลดเทมเพลต→กรอกข้อมูล→ตรวจไฟล์→ตรวจตัวอย่าง→ยืนยัน

ภาพอธิบายขั้นตอน ไม่ใช่ภาพหน้าจอของระบบปฏิบัติการ

  1. เลือก นำเข้าข้อมูลพื้นฐาน แล้วเลือกหัวข้อ แผนก/ตำแหน่ง/หมวด/ผู้ใช้/ร้าน
  2. กดดาวน์โหลดเทมเพลตแต่ละหัวข้อ เปิดไฟล์ใน Excel ใช้ชีต Data กรอกตั้งแต่แถว2 อย่าเปลี่ยนชื่อชีตหรือหัวตาราง
  3. นำเข้าแผนกและตำแหน่งก่อนผู้ใช้ เพราะผู้ใช้จะอ้างรหัสเหล่านี้ ใช้รหัสหมวดและร้านขององค์กรเอง
  4. บันทึกเป็น .xlsx ไม่เกิน10MB/1,000แถวต่อไฟล์ ไม่ใส่สูตร/macros/ลิงก์ภายนอก
  5. เลือกไฟล์ กด ตรวจไฟล์และแสดงตัวอย่าง ตรวจจำนวนเพิ่มใหม่/ข้ามซ้ำทุกครั้ง แล้วกด ยืนยันนำเข้า ภายใน30นาที

ขั้นตอน / หัวข้อ 4

กรอกเลขประจำตัวและจัดการข้อมูลซ้ำ

คอลัมน์ผู้ใช้วิธีกรอก
หมายเลขประจำตัวตัวเลข1–15หลัก เก็บเป็น Text เลือกคอลัมน์ใน Excel → Home → Number Format → Text ก่อนพิมพ์ เลข0นำหน้าต้องอยู่ครบ
รหัสบุคลากรรหัสไม่ซ้ำ เช่น EMP001 หากเว้นว่างระบบใช้ username
ชื่อ / นามสกุลแยกคนละคอลัมน์ ใช้ชื่อจริงตอนเปิดบริการ
รหัสแผนก / รหัสตำแหน่งใช้รหัสที่นำเข้าแล้ว ไม่ใส่ชื่อแทนรหัส
อีเมล / โทรศัพท์ / ประเภทบุคลากรกรอกตามหัวตาราง เว้นช่องที่ไม่จำเป็นได้ ไม่ใส่สูตร

เลขประจำตัวซ้ำในไฟล์หรือในฐานข้อมูลจะข้าม ไม่เพิ่มซ้ำ แต่รหัสบุคลากร/อีเมลชนกับคนอื่น หรือรหัสข้อมูลพื้นฐานอื่นซ้ำจะเป็นข้อผิดพลาด ต้องแก้ก่อนนำเข้าทั้งชุด ผู้ใช้ใหม่ทั้งหมดเป็นผู้เรียน รหัสแรก learn123456 และบังคับเปลี่ยน ไม่ได้รับสิทธิ์ Admin/ร้านจาก Excel

ขั้นตอน / หัวข้อ 5

เมื่อ Excel ไม่ผ่าน และแก้บัญชีผู้ใช้

  1. อ่านแถวและคอลัมน์ที่ระบบแจ้ง เปิด Excel ไปที่แถวนั้น แก้ข้อมูลแล้วบันทึกใหม่
  2. หากเลือกไฟล์ผิดหัวข้อให้เลือกใหม่ ไม่แก้หัวตารางเพื่อหลอกให้ผ่าน
  3. บัญชีบุคลากร → ค้นหาคน → แก้ไข เลือกแผนก ตำแหน่ง สถานะและบทบาท แล้วบันทึก
  4. Admin รีเซ็ตรหัสผู้ใช้อื่นได้ตามสิทธิ์ ระบบให้เปลี่ยนรหัสใหม่อีกครั้ง อย่าใช้การนำเข้าซ้ำเพื่อรีเซ็ต

ขั้นตอน / หัวข้อ 6

มอบหมาย Instructor และตรวจขอบเขต

  1. เลือกหมวดหลักสูตรที่ต้องการ แล้วกำหนดผู้ใช้ที่เป็น Instructor ให้ควบคุมหมวดนั้น
  2. ตรวจบทบาทในบัญชีบุคลากรและการมอบหมายหมวดให้ครบ Instructorควบคุมหลักสูตรทั้งหมดในหมวดที่ Adminกำหนด
  3. ให้ Instructor เข้าระบบด้วยบัญชีของตน ตรวจว่าเห็นเฉพาะหมวดที่มอบหมาย
  4. แผนก/ตำแหน่งปัจจุบันของคนแก้ได้ แต่รายงานรอบเก่าใช้ข้อมูล ณ สมัครเรียนเพื่อรักษาประวัติ

ขั้นตอน / หัวข้อ 7

สร้างหลักสูตรและกำหนดจำนวนบท

  1. เลือก จัดการหลักสูตร → สร้างหลักสูตร กรอกรหัส ชื่อ หมวด และรายละเอียด แล้วบันทึก
  2. เข้าแก้หลักสูตร เลือกเวอร์ชันร่าง สร้างกลุ่มบท/บทเรียนตามจำนวนที่ต้องการ กำหนดลำดับและบทจำเป็น
  3. ในแต่ละบทเพิ่มเนื้อหาเป็นวิดีโอ เอกสาร ภาพ บทความ หรือลิงก์ จะไม่แนบเอกสารก็ได้
  4. วิดีโอเลือกอัปโหลด MP4 หรือ YouTube หรือ URL .mp4โดยตรง ลิงก์ต้องเข้าถึงผ่าน HTTPS และใส่ระยะเวลาเมื่อแบบฟอร์มกำหนด
  5. แนบ PDF/ภาพ/ลิงก์กับบทนั้นและตั้งจำเป็นตามต้องการ เอกสารของบทแสดงใต้คลิปอัตโนมัติ ไฟล์อัปโหลดสูงสุด100MB

ขั้นตอน / หัวข้อ 8

นำเข้า Pretest / Posttest แบบ 4–6 ตัวเลือก

  1. เข้าแท็บ นำเข้าข้อสอบ กด ดาวน์โหลดเทมเพลตข้อสอบ Excel ใช้ชีต Questions และหัวตารางเดิม
  2. แต่ละแถวมีรหัสข้อไม่ซ้ำ PRETEST/POSTTEST/BOTH คำถาม ตัวเลือก A–Dจำเป็น E/Fเว้นว่างได้ ถ้ามีFต้องมีE
  3. คำตอบถูกเป็น A–F หรือ ก–ฉ ได้หนึ่งตัวเลือกเท่านั้น ใส่คะแนนเต็ม หมวดข้อสอบ และคำอธิบายตามเทมเพลต
  4. เลือกไฟล์ → ตรวจตัวอย่าง → ยืนยันนำเข้า ตรวจเฉลยของ Pretest/Posttest แยกกัน
  5. หากต้องแทนชุดร่าง ใช้ ล้างข้อสอบเดิมเพื่อนำเข้าใหม่ ยืนยันตามหน้าจอ ใช้ได้เฉพาะเวอร์ชันและชุดสอบร่างที่ไม่เคยมีการสอบ หากเผยแพร่แล้วให้สร้างเวอร์ชันใหม่
จำนวนครั้ง Posttest ไม่อยู่ใน Excel ตั้งที่รอบเรียนในระบบ ไม่มีข้อสอบอัตนัยในรุ่นนี้

ขั้นตอน / หัวข้อ 9

ตั้งชุดสอบ เผยแพร่ และเปิดรอบเรียน

  1. ตั้งค่า PretestและPosttest เป็นเผยแพร่ ตรวจจำนวนข้อ เวลาสอบ และการสุ่มตามที่ต้องการ
  2. เผยแพร่เวอร์ชันหลักสูตรเมื่อบท/สื่อ/ชุดสอบครบแล้ว เปิดแท็บ รอบเรียนและผู้เรียน
  3. กำหนดชื่อรอบ ปีงบประมาณ วันเริ่ม/จบ การสมัครเองหรือมอบหมาย เกณฑ์ดูวิดีโอและจำนวนครั้ง Posttestรวมทั้งหมด
  4. จำนวนครั้งเริ่มต้น1 หมายถึงสอบได้รวม1ครั้ง ไม่ใช่1ครั้งแล้วทำซ้ำอีก1ครั้ง ปรับได้1–100แต่ไม่ลดต่ำกว่าที่ใช้แล้ว
  5. เปิดสถานะรอบและมอบหมายผู้เรียนตามต้องการ Pretestบังคับก่อนเรียนแต่ไม่บังคับคะแนน Posttestบังคับอย่างน้อย1ครั้งก่อนจบแต่ไม่บังคับผ่าน

ขั้นตอน / หัวข้อ 10

ติดตามรายงานและแต้ม

  1. เลือกรายงานผลการเรียน กรองปี/รอบ/แผนก/สถานะตามสิทธิ์ แล้วตรวจข้อมูลก่อนส่งออก
  2. เลือกส่งออก XLSX/CSV/PDF ตามแบบฟอร์ม รอ workerสร้างไฟล์จนขึ้นพร้อมดาวน์โหลดแล้วกดดาวน์โหลด
  3. คะแนนสรุปใช้ Posttestสูงสุด ประวัติแผนก/ตำแหน่งใช้ ณ สมัครเรียน ไม่ย้ายย้อนหลังตามข้อมูลปัจจุบัน
  4. แต้มอัตโนมัติ:จบ20 สอบผ่านเกณฑ์30 สูงสุด≥90%เพิ่ม10 อย่างละหนึ่งครั้งต่อคนต่อรอบ สอบซ้ำไม่ให้โบนัสเดิมซ้ำ
  5. กรณีปรับแต้มให้ค้นหาคน ระบุจำนวนและเหตุผล ตรวจยอดก่อนยืนยัน ระบบเก็บ Ledger/Audit ไม่แก้หรือลบรายการเดิม
เปิดภาพเพิ่มเติมของหัวข้อนี้

ขั้นตอน / หัวข้อ 11

อนุมัติร้านและตั้งรางวัลคูปอง

  1. นำเข้าร้านหรือสร้างร้านใหม่ ร้านใหม่อยู่สถานะรออนุมัติ กำหนดผู้ใช้ที่ปฏิบัติงานร้าน
  2. Adminตรวจข้อมูลและอนุมัติร้านก่อนเปิดรับคูปอง การนำเข้า Excelไม่เพิ่มสิทธิ์ร้านให้อัตโนมัติ
  3. สร้างรางวัล ผูกร้านที่ใช้ได้ ใส่แต้มที่ใช้ มูลค่าส่วนลดและจำนวนคงเหลือ ตรวจหน่วยบาทในหน้าจอ
  4. ตัวอย่าง500แต้ม=5บาท /1000แต้ม=10บาท /1500แต้ม=20บาท คูปองมีอายุ90วันและใช้เฉพาะร้านที่ระบุ
  5. หากระงับร้านให้ระบุเหตุผลและตรวจผลกระทบต่อคูปองที่ยังไม่ใช้ในรายงานก่อนแจ้งผู้ใช้

ขั้นตอน / หัวข้อ 12

ขั้นตอนร้านรับคูปองและทำใบส่งเบิก

  1. ผู้ปฏิบัติงานร้านเข้าระบบ เลือก รับคูปองและส่งเบิก แล้วเลือกร้านของตน
  2. ขอผู้เรียนเปิดบัตรออนไลน์ กดแสดงรหัส นำรหัสมากรอกแล้วกด ตรวจคูปอง
  3. ตรวจชื่อผู้ถือ ชื่อร้าน มูลค่า วันหมดอายุ หากตรงกดรับคูปองและยืนยัน แล้วจึงให้ส่วนลด ห้ามรับจากภาพบัตรโดยไม่ตรวจระบบ
  4. เลือกระยะเวลารายงาน ทำเครื่องหมายคูปองที่ยังไม่ส่งเบิก กดสร้างใบสรุป ตรวจยอดก่อนยืนยัน
